# Data handling

Summary of data in **Veridian Motion**. See
[Data model & privacy](/veridian-motion/data-model-privacy) for detail.

<Note>
  Current Lovable builds use **synthetic data only**. Retention and deletion
  for real PHI follow the agency agreement after compliance migration.
</Note>

## What we collect

| Data | Source | Purpose |
| --- | --- | --- |
| Patient record | Admin enrollment / bulk import | Authentication, roster |
| Patient ID + PIN hash | Enrollment | Portal sign-in |
| Legal acceptances | First login | Versioned Terms consent |
| Body-map, complaint, questionnaire | Patient portal (MSK) | Triage context |
| Posture photos (up to 4) | Patient portal | Clinician review |
| AI exercise plan | Server | Clinician review until approved |
| Clinician notes | Clinician | Clinical record; optional patient share |
| Messages | Staff + patient | Append-only internal record |
| Medical Intake profile | Patient portal | Clinician red-flag review |
| Precision Rehab sessions / routines / certs | Patient portal | Self-directed rehab + PT review |
| Chess games / puzzles / progress / assignments / certs | Patient portal | Non-clinical cognitive wellness |
| Program entitlements / enrollments / billing snapshots | Admin | Licensing and invoice-support |
| Staff accounts + roles | Admin | Dashboard access |
| Audit events | Platform | Hash-chained; no PHI in payload |

## What we do not collect in logs

- Clinical narrative in application logs
- Raw photos in audit entries
- AI prompt/response content in standard logs

## Where data lives

United States regions via Lovable Cloud / Supabase unless dedicated
environment under contract.

## Retention and deletion

Per **agency agreement**. Export window at contract end; deletion procedures
and certificates on request.

## PDF export

Staff may export assessment **PDF** from the dashboard. Where configured, send
to an **allowlisted email**. Communication Record PDF is admin-only and
audit-logged.
