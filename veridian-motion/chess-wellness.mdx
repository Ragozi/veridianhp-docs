# Chess Academy

**Chess Academy** (app title; docs slug remains `chess-wellness`) is a
**licensed cognitive-wellness program** focused on patience, focus, and
problem-solving. It is **explicitly not clinical** — not a diagnosis tool,
therapy, or behavioral-health module.

Clinical authority stays with licensed clinicians. This program does **not**
diagnose.

<Note>
  Controlled by **`CHESS_ENABLED`**. Licensed **per facility** and **per
  patient seat** — see [Programs & licensing](/veridian-motion/programs-and-licensing).
  **Built / rolling out** on synthetic (pre-production) data — confirm
  activation for your deployment. Current Lovable builds use **synthetic data
  only**.
</Note>

## Board

Original **Veridian piece set** (in-house artwork) with:

- **4 board themes** (saved per device)
- **Drag-and-drop** and **tap-to-move**
- Smooth move animation
- Highlights for last move / check / legal moves
- Board flip
- Built-in sounds (generated in the browser — no audio files)
- Every square remains a **labeled button** for keyboard and screen-reader use

Puzzles, lessons, and drills use the **same board** (drag supported).

## Play

### Opponents

Opponents map to engine skill levels **2, 4, 5, 6, 7, 9, 10** on a **1–10**
scale whose nominal ratings run **400 to 2200**. Encouraging lines are
**pre-written** and are **not AI**.

| Opponent | Engine skill (1–10) |
| --- | --- |
| Rookie Rick | 2 |
| Casual Carla | 4 |
| Steady Sam | 5 |
| Sharp Sara | 6 |
| Tactician Tom | 7 |
| Master Mia | 9 |
| Grandmaster Grace | 10 |

### Difficulty controls

- A **10-segment opponent-strength control** the patient can raise or lower
  directly
- Optional **Adjust to my results** — moves the level automatically based on
  outcomes

## Engine

Veridian ships an **in-house engine** written for this product. It runs in a
**Web Worker** so the board stays responsive. Recap analysis uses **genuine
engine evaluation** (not an approximation).

Engine design includes:

- 0x88 board representation
- Negamax with principal-variation search
- Iterative deepening
- Transposition table
- Quiescence search
- Null-move pruning
- Tapered piece-square evaluation
- Mate-distance scoring so it finishes won endgames

**Licensing:** the rules library is **BSD**; the bundled engine **avoids GPL
constraints**. A stronger **separate engine process** remains **Roadmap**
pending license review.

## Game recap

After a game, **Game recap** lets the patient:

- Step through the game on the board
- View a **who was ahead** graph
- See a better-move arrow on mistakes
- Read standard notation marks (`!`, `?!`, `?`, `??`)
- **Try it again** from the position before a mistake

Accuracy is a **game measure** derived from engine evaluation.

## Academy curriculum

**26 lessons** across **4 chapters**, drawn from **Dr. Mikhail Korenman's**
*A Handbook for Chess Players*, with **175 board diagrams** rendered as real,
playable-looking boards (not static images).

| Chapter | Focus |
| --- | --- |
| General Chess Principles | Foundational play |
| Chess Tactics | Tactical patterns |
| Basic Endgame Knowledge | Endgame techniques |
| Basic Principles of Openings | Opening ideas |

Credit: **Dr. Mikhail Korenman**.

## Puzzles, challenges, and ranking

| Area | Detail |
| --- | --- |
| **Puzzles** | Currently **36 checkmate-pattern** puzzles on the Veridian board |
| **Challenges** | Daily puzzle, **Rush (timed puzzle sprint)**, Ladder |
| **Ranking & seasons** | Personal rating, tiers, season points, streaks — **solo only**, no patient-vs-patient |
| **Instructor assignment** | Staff assign specific activities to a patient |

### Seasons

Seasons follow **fiscal quarters (Q1–Q4)**. The current season is resolved by
**date**, so rollover is automatic. On rollover, **season points reset**;
**rating** and **streaks** persist.

### Known gap

The puzzle set is currently **36 checkmate-pattern puzzles**, so the tactics
lessons (pin, skewer, fork, discovered attack) do **not** yet have matching
practice puzzles. Expanding the puzzle library to match the curriculum is
**Roadmap**.

## Corrections security design

- **No chat** and **no matchmaking** between patients
- **No patient-vs-patient play**
- Engine and puzzle content run **without outbound chess API** calls

## Licensing
